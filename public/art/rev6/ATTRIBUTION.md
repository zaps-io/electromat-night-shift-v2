# Rev 6 art pass assets

Generated with the OpenAI Images API (model gpt-image-2), then post-processed on the box
(seamless high-pass for asphalt, luminance-to-alpha for paint decals and the tree/city strip,
horizon wrap fix and ground darkening for the sky, downscale and WebP/JPG compression).
Generic prompts, no vendor names, no logos. The Zaps wordmark is never generated; use public/brand/*.svg only.
sign_* images are generic PRICE / OPEN / EV CHARGING / PLUG IN faces.
