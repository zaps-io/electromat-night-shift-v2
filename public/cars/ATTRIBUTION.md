# EV hulls

`ev-sedan.glb` and `ev-suv.glb` are authored for ELECTROMAT Night Shift v2.

Both are lofted BufferGeometry packed to glTF 2.0 — not BoxGeometry, cylinder-disc wheels, or lathe loaves. Generated by `src/cars/sedan.ts` / `src/cars/suv.ts` via `npm run export:sedan`.

Sedan: belt at the sill, greenhouse glass on that belt, taut arches, ten-spoke rims, rear haunch wider than the door, short closed trunk, wraparound red light bar.

SUV: taller greenhouse / ride height, same EV cues, used as the dark second body type in the opening lot.

Original Zaps Electromat geometry. Not copied from v1.
