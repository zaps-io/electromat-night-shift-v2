# EV sedan GLB

`ev-sedan.glb` is authored for ELECTROMAT Night Shift v2.

It is a lofted four-door notchback EV sedan (BufferGeometry → glTF 2.0), not a BoxGeometry, cylinder-disc wheel, or lathe loaf. The hull is generated by `src/cars/sedan.ts` and packed by `src/cars/glb.ts` via `npm run export:sedan`.

Features: horizontal belt at the window sill, greenhouse sitting on that belt (separate glass primitive), taut wheel-arch lips, ten-spoke alloy rims, rear haunch wider than the door, short closed trunk, wraparound red light bar. No fin. No pickup bed.

This is original geometry for Zaps Electromat. It is not copied from `zaps-io/electromat-night-shift` v1.
